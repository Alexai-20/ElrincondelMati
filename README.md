# ElrincondelMati
CoffeeHub es una plataforma para administrar una cafetería, permitiendo gestionar productos, clientes y pedidos, aplicando buenas prácticas de desarrollo seguro mediante DevSecOps.
## Objetivo
Crear un sistema que permita administrar las operaciones principales de una cafetería, incorporando automatización, seguridad y control del ciclo de desarrollo.
