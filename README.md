# El Rincon del Mati 🧉

Sistema de gestión para una cafetería con enfoque DevSecOps.

## Objetivo

Crear un sistema que permita administrar las operaciones principales de una cafetería, incorporando automatización, seguridad y control del ciclo de desarrollo.

## Funciones

- Gestión de productos (CRUD)
- Gestión de pedidos
- Roles de usuario
- Pipeline CI/CD preparado

## Tecnologías

- HTML
- CSS
- JavaScript
- Node.js
- Express

## Seguridad

- Gitleaks
- Trivy
- CodeQL
- Dependabot
