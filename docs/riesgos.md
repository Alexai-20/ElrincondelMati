# Riesgos de seguridad

1. Robo de credenciales:
Mitigación: MFA, cifrado de contraseñas y HTTPS.

2. Acceso no autorizado:
Mitigación: roles y permisos.

3. Inyección:
Mitigación: validación de datos.

4. Secretos expuestos:
Mitigación: Gitleaks y GitHub Secrets.

5. Dependencias vulnerables:
Mitigación: Trivy, Snyk y Dependabot.
