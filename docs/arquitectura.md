# Arquitectura El Rincon del Mate 🧉

## Frontend
Interfaz donde los usuarios pueden visualizar productos y realizar acciones.

## Backend
Servidor encargado de procesar solicitudes y gestionar la lógica del sistema.

## Seguridad
Se aplican controles DevSecOps mediante:

- Gitleaks
- Trivy
- CodeQL
- GitHub Actions

## Flujo del sistema

Usuario
↓
Frontend
↓
Backend
↓
Base de datos
